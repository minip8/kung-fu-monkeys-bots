Write a bot.
Bank the bananas.

Kung Fu Monkeys is an arena brawler where bananas fly like boomerangs. On the ladder your code plays it five against five: one WebAssembly module drives a whole team that harvests bananas, carries them home, steals from the other side and fights for every one. First team to bank 40 wins.

Sign in with GitHub Sign in with Google Read the contest guide

Harvest

Trees are the only supply. Each lays a banana on its beat, and stops when its cell is full.

Carry

A monkey holds three. The same bananas are its cargo and its weapon: bank the last one and it is unarmed.

Bank

Stand in your home zone: one banana banked, one point, every two turns.

Steal and fight

An empty home leaks points to raiders. A kill drops the cargo; a perfect dash catch takes the banana out of the air.

1

Write

A bot is a directory of C++ (or C) sources over a small freestanding SDK. Every tick it reads an observation of what its monkey sees and returns one input: move, aim, dash, throw, call.

Start from the example bots.

2

Test

The kfm tool builds your bot exactly as the ladder does and plays it against the reference bots on your machine, with the engine's own headless runner.

Deterministic: every game replays bit for bit.

3

Climb

Submit the sources. The ladder builds them in a sandbox, checks the module, and pairs your team {% if l.round_minutes > 0 %}every {{ l.round_minutes }} minutes {% endif %}with teams near its rating.

Glicko-2 ratings, public results, replays you can watch.

Quick start

uv tool install kfm-cli                 # the PyPI name; the command is kfm (pipx works too)
git clone --depth 1 https://github.com/minip8/kung-fu-monkeys-bots.git
cp -r kung-fu-monkeys-bots/examples/starter mybot && cd mybot
kfm login                               # the browser confirms; a submit token is stored
kfm build                               # out/bot.wasm with the ladder's recipe
kfm test                                # ranked-shape 5v5 games against ref:hard
kfm submit --wait --activate            # built and validated by the ladder, then your ranked bot

Sign in and create a team here first. Docker is used for the ladder's own build image (or kfm build --local with a clang that targets wasm32). Everything else is in the repository.
